# Inventory Management System

A Java Console-based Inventory Management System developed using Object-Oriented Programming principles and layered architecture.

## Features

- Admin Login
- Product Management
- Supplier Management
- Inventory Tracking
- Exception Handling
- File Handling (Upcoming)

## Technologies Used

- Java
- Eclipse IDE
- Object-Oriented Programming
- Java Collections Framework
- File Handling

## Project Structure

```
src
├── app
├── menu
├── model
├── service
├── storage
├── util
└── exceptions
```
