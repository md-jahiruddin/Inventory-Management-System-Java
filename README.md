# 📦 Inventory Management System

A console-based Inventory Management System built using **Core Java**, demonstrating **Object-Oriented Programming (OOP)**, **Java Collections Framework**, and a clean layered architecture. The application enables efficient inventory management through a menu-driven interface.

---

## ✨ Features

- 🔐 Admin Login
- 📦 Product Management (Add, Update, Delete, Search)
- 🚚 Supplier Management
- 📊 Inventory Tracking
- ⚠️ Exception Handling
- 🏗️ Layered Architecture
- 💾 File Handling (Planned)

---

## 🛠️ Technologies Used

- Java
- Eclipse IDE
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/md-jahiruddin/Inventory-Management-System-Java.git
   ```

2. Open the project in Eclipse IDE.

3. Run `Main.java` to start the application.
